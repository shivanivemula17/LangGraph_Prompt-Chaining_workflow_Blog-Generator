# Blog Generator using LangGraph – Sequential Workflow

## Overview

This project demonstrates how to build an AI-powered Blog Generator using **LangGraph and Large Language Models (LLMs)**.

The application follows a **Sequential Workflow (Prompt Chaining)** approach, where multiple LLM tasks are executed one after another to generate a complete blog.

Instead of generating the entire blog in a single step, the workflow divides the process into two stages:

1. **Blog Outline Generation:** The LLM receives a blog title and generates a structured outline.
2. **Blog Content Generation:** The LLM uses the original title and generated outline to create detailed blog content.

The output of the first node becomes the input to the second node, demonstrating how LangGraph manages state and coordinates sequential LLM operations.

## Workflow Architecture

```text
                 START
                   |
                   v
             Input Blog Title
                   |
                   v
          +--------------------+
          |  Create Outline    |
          |      (LLM)         |
          +--------------------+
                   |
                   v
            Generated Outline
                   |
                   v
          +--------------------+
          |   Create Blog      |
          |      (LLM)         |
          +--------------------+
                   |
                   v
            Generated Blog
                   |
                   v
                  END
```

## How It Works

### 1. Define Workflow State

A `TypedDict` named `BlogState` defines the information shared between workflow nodes.

It contains three fields:

- `title`: Input topic or blog title.
- `outline`: Outline generated by the first LLM node.
- `content`: Final blog content generated by the second LLM node.

### 2. Create Outline Node

The `create_outline` function:

- Receives the blog title from the workflow state.
- Creates a prompt requesting a detailed blog outline.
- Sends the prompt to the LLM.
- Stores the generated outline in the workflow state.

### 3. Create Blog Node

The `create_blog` function:

- Retrieves the blog title and generated outline.
- Creates a prompt using both inputs.
- Sends the prompt to the LLM.
- Generates detailed blog content.
- Updates the workflow state with the generated content.

### 4. Build the LangGraph Workflow

- Initialize a `StateGraph` using `BlogState`.
- Register `create_outline` and `create_blog` as workflow nodes.
- Connect the nodes using directed edges.
- Define `START` and `END` to establish the execution flow.

### 5. Compile and Execute

Compile the graph using `graph.compile()` and execute it using `workflow.invoke()` with the initial blog title.

The final state contains the input title, generated outline, and completed blog content.

## Workflow Pattern: Sequential Workflow (Prompt Chaining)

This project implements the **Prompt Chaining** pattern.

Prompt Chaining breaks a complex task into smaller LLM-powered tasks, where the output of one task is passed to the next task.

In this project:

- First LLM call → Generates the blog outline.
- Second LLM call → Generates the complete blog using the outline.

This approach makes the generation process more structured and demonstrates how multiple LLM calls can work together in a single LangGraph workflow.

## Language Model

This project uses **Qwen2.5-0.5B-Instruct**, an instruction-tuned language model from Hugging Face.

The model is integrated using LangChain's `HuggingFacePipeline` and runs locally through the Transformers pipeline.

No hosted LLM API key is required for local inference.
